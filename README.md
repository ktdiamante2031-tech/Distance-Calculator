# Project Title : Distance Calculator

## Description of the Distance Calculator
This project named Distance Calculator uses the Distance Formula for a 2D plane which is, Square root of (X2-X1)^2 (Y2-Y1)^2 and asks you for the values of them and solves it.

## How do you run this code?
You can run this code with any Python IDE or any IDE that supports Python 3.
Then you can run the program on the IDE. Next, enter the values of X1, X2, Y1, and Y2. Finally, check the distance displayed on the screen

## Inputs needed for the program?
You only need to input the value of the variables, X1, X2, Y1, and Y2.

## Sample Output
- Enter x1: 2
- Enter y1: 3
- Enter x2: 7
- Enter y2: 8
- The distance between the two points is 7.07
